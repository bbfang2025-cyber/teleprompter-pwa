# 极简提词录像（Apple-Style Mobile Teleprompter PWA）

> 在线体验地址（手机 Safari / Chrome 直接打开）：**https://tici.danaofu.top**

专为手机竖屏与横屏口播打造的**极简苹果风纯前端提词录像工具**。打开网页即可前置高清取景、在磨砂玻璃悬浮窗里看词口播，成片只录纯净人像与声音，绝不把提词框录进视频。零后端、无需下载安装 App，拍完一键回看并存入手机相册。

---

## 核心特性

- **极简苹果原生相机手感**：全屏取景 + 安全区自适应（适配灵动岛与底部手势条），支持拖放与缩放的磨砂玻璃悬浮提词窗（可紧贴摄像头防眼神飘移），底部红白快门、大号暂停/继续键、稿件库与设置抽屉。
- **横竖屏自适应 & 高清满幅**：默认**跟随手机方向**（关闭系统「竖排方向锁定」后，横拿自动拍满 16:9、竖拿自动拍满 9:16），优先申请 1920×1080 / 30fps 高清前摄；针对 iPhone 17 Pro Max 等机型支持正方形/宽幅传感器的安全探索，取景与成片比例 1:1 对应、无多余黑边。
- **贴合真人口播的滚屏细节**：3-2-1 倒计时、可调首行起读缓冲（默认 1.8s）、`requestAnimationFrame` + `translate3d` 丝滑滚屏（`10–110 px/s`）、字号/透明度调节、多篇本地稿件实时保存（`localStorage`）、试滚语音跟读（Beta）与屏幕常亮（Wake Lock）。
- **双端高质量成片与自动更新**：优先导出 H.264/AAC MP4（iPhone Safari 与剪映原生友好），安卓端若输出 WebM 会自动修复精确毫秒级时长与时间戳基线；支持成片左右翻转重导、系统分享直存相册及版本自动破缓存升级。

## 使用方法

1. 用手机 Safari 或 Chrome 打开 HTTPS 地址。允许摄像头权限后可预览，点击快门时会单独请求麦克风。权限不可用时可选择「纯黑背景体验提词」。
2. 在「稿件库」新建、编辑或切换稿件。稿件和设置存放在当前浏览器的 `localStorage`。清除站点数据、更换浏览器或换设备会影响旧稿件的访问。
3. 拖动提词窗顶部移动位置，拖动右下角改变尺寸，在正文区域上下滑动可手动定位。设置中可重置位置与大小，并调节字号、透明度、速度和起读缓冲。
4. 点「试滚」可排练。支持 Web Speech API 的浏览器可以开启中文语音跟随，识别不可用时会切换至匀速。语音服务可能由浏览器联网提供。**正式录像始终匀速滚动，麦克风供录音使用。**
5. 点快门后，摄像头和麦克风就绪才开始 3 秒倒计时。倒计时可以取消。录制中用左侧按钮暂停或继续，再点快门结束；暂停期间也可以直接结束。
6. 在回看页播放视频、分享或下载。「重拍」会释放当前回看文件并重新打开取景，请先保存要保留的片段。

网页通过浏览器直接使用手机前摄，优先申请 1920×1080、30 帧的采集格式。设备拒绝该格式时，会尝试 720p，再使用浏览器可提供的格式。按目标画幅裁切时使用相机实际提供的像素，回看页显示导出分辨率。浏览器录像与手机原生相机各自使用自己的录像设置。

前置取景是镜像，默认成片与 iPhone 原生相机关闭「镜像前置镜头」时一致。回看可点「左右翻转」，网页会根据原片生成保留音频的镜像文件，处理时间约等于片长，可以取消。生成后分享或下载会使用当前方向的文件；点「恢复原方向」可回到原片。

首次使用默认「跟随手机」，会自动按当前横拿或竖拿切换 **9:16 竖屏** 与 **16:9 横屏**（旧版固定设置会自动升级为跟随手机）；如果手机开启了系统「竖排方向锁定」，横拿时网页不会旋转，请下拉控制中心关闭方向锁定后再横拿，即可拍满完整宽幅 1920×1080。如果浏览器交付 3:4 / 1:1 等传感器画面，预览与成片会同步居中铺满目标画幅，不留黑边（在 19.5:9 超长屏幕上预览外框微弱细线内即为实际成片取景范围）。

竖拿手机时也可点击顶部或设置切换固定画幅：对于配备正方形前摄传感器的机型（如 iPhone 17 Pro Max），竖拿切横屏时会使用合规的 `ideal` 比例安全探测宽幅/方形流；若当前浏览器竖拿仍强制只返回窄竖屏流，页面会在设置说明中诚实提示你横拿手机以获得完整横屏视野。在设置中选「跟随手机」可随时恢复自动旋转；开拍前旋转会取消倒计时，录像中旋转会结束并保留当前片段。

滚屏速度为 **10–110 px/s**，默认和「适中」 **30 px/s**，「慢」 **20 px/s**。底部有「慢 / 适中 / 快」与 `− / +`，设置里有速度滑块。字号为 **20–48 px**，透明度设置控制提词窗背景的不透明度，起读缓冲为 **0–3 秒**，默认 **1.8 秒**。

## 录像与保存

| 场景 | 当前行为 |
| --- | --- |
| 编码器选择 | 优先尝试 H.264/AAC 的 MP4，随后尝试通用 MP4、WebM 和浏览器默认编码。最终扩展名按实际容器确定。 |
| WebM 时长 | 按媒体包时间戳和 `TimestampScale` 写入 `Duration`。明显异常的时间原点才会校正。校验失败时提供原始文件，并在回看界面提示。 |
| 录制被打断 | 麦克风或摄像头中断、画面停止更新或切到后台时结束本段录制，尽力保留已录数据。收到的数据达到约 160 MiB 时会自动收尾，最终大小可能略高。 |
| MP4 | 点击「保存到手机相册」尝试打开系统分享面板。如果面板提供「存储视频」或相册目标，可在那里选择保存。 |
| WebM | 点击「分享 WebM」或「下载文件」。相册和剪映对 WebM 的支持取决于设备和版本。 |
| 分享不可用 | 按钮会降级为下载。分享调用失败后，也可直接点「下载文件」。下载文件通常出现在浏览器下载列表或系统文件应用中。 |

录像文件在浏览器内处理。离开页面前请保存需要的成片，回看文件随页面生命周期释放。屏幕常亮依赖浏览器和系统是否接受 Wake Lock。

## 部署与添加到主屏幕

发布需要 `index.html`、`manifest.json`、`icon.svg` 和 `version.json`，四者放在同一目录。应用清单与图标用于主屏幕入口，版本文件用于检查更新。可在电脑上用 `localhost` 开发调试，手机访问请使用 HTTPS。项目提供 PWA 清单，完整的离线启动与加载目前没有 Service Worker 支持。

- **GitHub Pages**。在 `Settings → Pages → Build and deployment` 选择 `Deploy from a branch`，再选包含静态文件的分支与目录。 [GitHub Pages 发布说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
- **Cloudflare Pages**。通过 Direct Upload 上传静态文件所在的目录或压缩包。 [Cloudflare Pages 上传说明](https://developers.cloudflare.com/pages/get-started/direct-upload/)
- **iPhone Safari**。在浏览器分享菜单里查找「添加到主屏幕」。
- **安卓 Chrome**。在浏览器菜单里查找「添加到主屏幕」或安装入口。显示内容取决于浏览器。
- **微信内打开**。页面会提示切到 Safari 或手机上的默认浏览器使用录像功能。

## 本地复验

以下命令从项目目录运行。媒体样本保存在系统临时目录，脚本会打印测试结果。

```powershell
# 需要 Node.js 22 或更新版本，以及 PATH 中的 ffmpeg 和 ffprobe
node .\tests\webm-duration.cjs

# 浏览器回归还需要本机 Google Chrome 和 Playwright
npm install --prefix tests --no-save --no-package-lock playwright@1.65.1
node .\tests\browser.cjs
```

`webm-duration.cjs` 检查 WebM 时间戳、时长和可寻址性。`browser.cjs` 用桌面 Chrome 移动视口及假摄像头、假麦克风，覆盖录制、导出、分享降级、触控和异常恢复。桌面结果不覆盖真机系统相册与剪映导入。技术变更、已测结果和真机验收项见 [WORKLOG.md](./WORKLOG.md)。

### 画幅改动的发布验收

- 用四角和左右都有标记的相机样本检查预览截图和成片像素。用 3:4 相机源确认默认 9:16 的画面铺满上下，再测竖拿点横屏、横源转竖屏、横源保留边缘，以及镜像文件。
- 检查切换比例时沿用同一条摄像头流，手机旋转跟随和手动固定是两条独立路径。再用 Android 系统里的 Chrome 完成旋转、录制、回看和下载，检查约 30 秒样本的尾部画面和音轨。
- 用高清竖向相机样本解码原片和镜像文件，确认两者都是 1080×1920 且有音轨，再模拟 1080p 和 720p 请求均被拒绝并检查降级。
- iPhone 的摄像头视野须在真机上对照同一距离、同一场景的原生前摄。浏览器或模拟器验证结果应标明环境。推送后检查正式网址上的页面版本及关键流程。
